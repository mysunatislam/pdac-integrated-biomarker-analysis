# Results

Final and supporting outputs are organized by result type.

- `tables/discovery`: DEG tables and CP-aware malignant-switch gene lists.
- `tables/spatial`: GSE208536 mapping files, stage-association statistics, and corrected hub summaries.
- `tables/enrichment_ppi`: GO/KEGG enrichment, Cytoscape/MCODE summaries, PPI hub ranks, and shared hub-gene tables.
- `tables/mirna`: EV/plasma miRNA discovery, model-performance, and curated miRNA-hub evidence tables.
- `figures/manuscript`: final manuscript figures in both PNG and PDF.
- `figures/components`: supporting component figures in both PNG and PDF.
- `networks`: GraphML files for portable network review.
